Self-hosted fonts, so the first paint never waits on a third-party stylesheet. Both are Latin subsets of variable fonts (one file covers every weight), licensed under the SIL Open Font License 1.1.

- `geist-latin.woff2`: Geist by Vercel (https://github.com/vercel/geist-font/blob/main/OFL.txt). Used by the Desk, Desktop and Garden.
- `jetbrains-mono-latin.woff2`: JetBrains Mono by JetBrains (https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt). Used by the Terminal.
